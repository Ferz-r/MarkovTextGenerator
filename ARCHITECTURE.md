# Архитектура

## Ответственность объектов

| Компонент | Ответственность |
| --- | --- |
| `Tokenizer` | Обучение словаря, преобразование текста в ID и обратно |
| `CharacterTokenizer` / `RegexTokenizer` | Разбиение текста на символы или слова, числа, пробелы и пунктуацию |
| `TransitionIndex` | Компактное хранение переходов и частот коротких контекстов |
| `MarkovChain` | Корпус, обучение, генерация, тематические индексы и состояние модели |
| `ModelSettings` / `ModelStats` | Настройки и результат запроса статистики |
| `MarkovService` | Синхронизация операций, подготовка и публикация нового состояния |
| `storage` | Чтение и атомарная запись снимка на диск |
| `corpus` / `file_corpus` | Получение обучающих текстов из внешних источников и файлов |
| `api` | Проверка HTTP-запросов, ответы и передача событий прогресса |
| `app.py` | Создание приложения, загрузка модели и подключение интерфейса |

## Зависимости

`api` вызывает `application`; `application` использует `domain` и файловое хранилище
из `infrastructure`. `infrastructure` может использовать общие события прогресса.
`domain` не импортирует API, сервис, файловое хранилище или веб-фреймворк.
Типы настроек используют Pydantic, но определены независимо от транспортных схем.

Функции загрузки файлов и HTTP-маршруты остаются функциями: у них нет состояния,
которое оправдывало бы отдельную иерархию классов. Общий контракт токенизаторов
представлен одним ABC; дублирующего неиспользуемого Protocol нет.

## Обновление модели

1. Сервис захватывает блокировку.
2. Создаёт новую модель и обучает её на новом корпусе или объединении старого и нового.
3. При изменении типа токенизатора, контекста или частоты готовит известные темы.
4. Сохраняет кандидат во временный файл и атомарно заменяет снимок.
5. Публикует новый объект и настройки в памяти.

Ошибка обучения или записи сохраняет действующую модель и прежний файл.
Изменение только длины генерации сохраняет новые настройки перед изменением
действующего объекта и не требует обучения.

Полное обучение при добавлении текстов необходимо для пересчёта частот словаря.
В сервисе корпус не дублируется: его единственный владелец — `MarkovChain`.
Свойство `texts` возвращает неизменяемый снимок последовательности.

## Снимки

Формат версии 1 сохранён: словарь, тексты, упакованные переходы, темы и настройки.
Модель восстанавливает своё состояние через `from_state`, индекс проверяет все
упакованные коды токенов. Сервис не читает и не меняет приватные поля модели.
Файловое хранилище запрещает десериализацию Python-классов.

## Точки расширения

Новый токенизатор наследует `Tokenizer`, реализует `_split` и добавляется в выбор
типа модели. Новый источник корпуса предоставляет `Callable[[], list[str]]` для
`create_app`. Политику сохранения и синхронизации меняют в сервисе, HTTP-представление
— в `api`, алгоритм генерации — в модели.
