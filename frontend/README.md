# Марков — студия текста

Интерфейс на HTML, CSS и JavaScript без сборки и npm-зависимостей.
FastAPI раздаёт файлы этой папки и API с одного адреса.

Из корня репозитория:

```sh
cd backend
uv sync
uv run python main.py
```

Откройте http://127.0.0.1:8000 после окончания обучения модели.

Возможности: генерация с началом и темой, копирование результата, статистика,
добавление обучающих текстов и замена корпуса с подтверждением. Отдельные тексты
разделяются пустой строкой. Обучение действует до перезапуска сервера.
При запросах отображаются состояние загрузки и ошибки; интерфейс адаптирован для телефона.

`index.html` — разметка, `styles.css` — оформление, `app.js` — работа с `/api/v1`.
Google Fonts используются при доступной сети; предусмотрены локальные запасные шрифты.

Настройки модели доступны в интерфейсе и через `POST /api/v1/settings`:
`{"n_gramm": 3, "min_frequency": 5, "max_length": 100}`.
Текущие значения возвращает `GET /api/v1/model` в поле `settings`.
Контекст (1–50) и частота (1–100000) пересчитывают модель на текущем корпусе.
Длина (1–10000 новых токенов) применяется без обучения. Настройки действуют до
перезапуска и общие для всех пользователей. Значения старта задаются в `backend/main.py`.

При обучении и пересчёте интерфейс показывает прогресс текущего этапа, число
обработанных элементов и время этапа. Процент начинается заново на каждом этапе.
`POST /api/v1/train/stream` и `/api/v1/settings/stream` возвращают SSE-события
`start`, `progress`, `complete` или `error`; обычные JSON-методы сохранены.
Прерывание соединения не отменяет уже запущенное обучение.

Кнопка «Добавить .txt» выбирает файл без чтения его содержимого в браузере.
Кнопка «Обучить модель» отправляет файл через multipart/form-data в
`POST /api/v1/train/file/stream`. Введённый вручную текст можно отправить вместе
с файлом. «Убрать файл» отменяет выбор. Бэкенд читает абзацы из временного файла,
поддерживает UTF-8, UTF-16 с BOM и Windows-1251; временный файл удаляется после обработки.
Ограничений размера файла, количества и длины текстов нет.
